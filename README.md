# Linger（去留）Android

一个受“随机回顾照片”产品理念启发的 Android 本地相册整理应用。此项目为独立实现，不包含原 iOS App 的代码、商标素材或私有资源。

## 当前版本功能
- 使用 MediaStore 扫描本机照片与视频
- 随机抽取一组媒体（默认 15 项，可在设置中调整）
- 上滑标记删除、下滑收藏、左滑跳过、右滑保留
- 一组结束后统一确认删除；调用 Android 系统删除授权界面
- 浏览、删除、估算释放空间和收藏统计
- 收藏列表、照片/视频/混合/近 30 天筛选
- 本地保存统计与浏览记录，不上传媒体

## 环境
- Android Studio（建议最新稳定版）
- JDK 17
- Android SDK Platform 35
- Android 11+（minSdk 30）

## GitHub 在线构建
1. 在 GitHub 新建一个空仓库，例如 `LingerAndroid`。
2. 解压本项目 ZIP，把其中所有文件和隐藏目录（尤其 `.github`）上传到仓库根目录。
3. 推送到 `main` 分支后，打开仓库的 **Actions**。
4. 进入 **Build Android APK** 工作流，等待绿色成功标记。
5. 打开本次运行，在 **Artifacts** 下载 `linger-debug-apk`。
6. 解压后得到 `app-debug.apk`，传到 Android 手机安装。

也可以在 Actions 页面点击 **Run workflow** 手动触发构建。

## 本地构建
在项目根目录执行：
```bash
gradle assembleDebug
```
APK 输出位置：
`app/build/outputs/apk/debug/app-debug.apk`

## 重要说明 / 当前限制
- 首次启动需要授予照片和视频读取权限。Android 14/15 的“仅选择部分照片”权限模式下，用户可能需要在系统设置中扩大授权范围，才能扫描完整媒体库。
- 删除会调用 Android 系统确认流程；用户取消系统确认时不会删除。不同 Android 厂商对“最近删除”的实现可能不同。
- 收藏目前保存在 Linger 应用内部，不会自动写入 Google Photos 或各手机厂商相册的收藏分类。
- 当前版本以基础随机回顾为主，尚未实现“回到那天”双指展开、桌面小组件、相似照片识别、云端同步、长视频倍速和付费系统。
- 浏览记录以本机 URI 为标识。卸载应用会清除应用私有统计和收藏记录。
- 此为第一版可运行工程，正式发布前应在目标手机型号上完成权限、媒体解码、删除和恢复测试，并配置正式签名密钥。

## 隐私
应用不包含网络权限，也没有照片上传逻辑。媒体读取与处理在设备本地完成。
